# Sachdevayogita46-arch.github.io
Renewable Society is a smart city project by Rohil, Rishit, Ryan, Aditya, and Kovid. We build green infrastructure using vertical wind turbines powered by passing cars, solar houses, copper-coil wireless car chargers, smart IR-sensor dustbins, and flame-sensing fire alarms to create a clean, safe, and fully self-sustaining future community.
